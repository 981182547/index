云同步 · GitHub 私有仓库

账本会存成仓库里的一个 JSON 文件，每次改动是一次 commit（自带历史，可回滚）。
仓库必须是 Private，否则收入明细全网可见。
令牌只存在这台设备的浏览器里，只发给 api.github.com，不会进 URL。
建 token：GitHub → Settings → Developer settings → Personal access tokens → Fine-grained → 只勾这一个仓库 → Repository permissions 里 Contents: Read and write。

备份与导出

导出的 JSON 是完整账本（含全部字段），可以在任何设备用「导入」还原。
CSV 用 Excel 直接打开（已带 BOM，中文不乱码）。
